Privacy in the current static build.

This page describes the Wiki as prepared on August 27, 2026. It must be updated before adding analytics, advertising, forms or user accounts.

Current status: the project contains no analytics script, advertising network, account system, comments, payment form or identity-document upload. It does not ask for game passwords, KYC documents or payment details.

Basic hosting records

When the site is publicly hosted, the hosting provider may process standard server logs such as IP address, requested URL, browser information, timestamps and security events. Retention and processing depend on the provider selected for launch and must be documented after deployment.

Browser storage

The current code uses normal browser navigation and interface state. It does not intentionally store a tracking identifier in cookies or local storage. If analytics or consent controls are added later, this section must change before those tools go live.

External links

Links to FatalFrontier.com, Paydirt Games, Reddit, independent reviews, Discord or payment-related source pages leave this Wiki. Those sites can collect data under their own privacy policies. An external link is a source or route, not an endorsement.

Sensitive information

Do not send this Wiki passwords, launcher tokens, payment details, Social Security information or identity documents. The site has no feature that requires them. Official account, KYC, payment and withdrawal questions belong with Paydirt Games or its named processors.

Age and prospecting

This Wiki is informational. Paydirt’s current Terms contain separate age, identity and location requirements for the game and Prospecting Mode. Readers should use the official Terms rather than infer eligibility from access to a guide.

Changes to this policy

The page will be revised when the production host, analytics, advertising or contact method changes. The modified date should move with the implementation, not merely with wording.

Questions

A production contact address has not yet been configured. For game accounts, payments or technical support, use the official Fatal Frontier Support page. For this Wiki’s editorial standards, see About.
