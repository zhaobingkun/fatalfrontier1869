# Local web fonts

These Latin WOFF2 files are self-hosted to remove the render-blocking Google Fonts request chain.

- Barlow Condensed — The Barlow Project Authors
- DM Mono — The DM Mono Project Authors
- Rye — Sorkin Type Co
- Space Grotesk — The Space Grotesk Project Authors

All four families are distributed under the SIL Open Font License 1.1. See `OFL-1.1.txt` in this directory.
