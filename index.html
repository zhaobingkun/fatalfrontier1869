What this Wiki covers

One source-backed route through Early Access.

Fatal Frontier 1869 combines a free single-player survival game with an optional real-value prospecting layer. That unusual combination creates practical questions about the launcher, Pioneers, Traits, supplies, Claims, Skill Checks, extraction, currency and withdrawals. Each page answers one of those questions directly and marks facts that still require current-build testing.

Start with Gameplay if you want to understand the expedition loop. Use Is It Legit? before making a trust decision, and read Cost & Free before spending.

Frequently asked questions

Is the game free?

The base survival game is free. Optional prospecting uses Passes and Claims and is restricted by the current Terms.

Can players withdraw real money?

Eligible users have a documented payout route after finding, recovering and extracting Gold. A payout mechanism is not a profit guarantee.

Is this the official site?

No. This is an independent Wiki. Official downloads and rules always link back to Paydirt Games.
